# 快速开始

## 1. 安装

```bash
pip install -r requirements.txt
```

或直接下载 Releases 中的 `NisslQuant.exe`（Windows 10/11，免安装）。

## 2. 一张图的完整流程

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | `文件 → 打开文件夹` | 支持 jpg/png/tif/bmp |
| 2 | 「① 勾画 ROI」 | 沿颗粒层外缘逐点单击，Enter 闭合；右键撤销 |
| 3 | 「② 浅染参考」 | 在层内最浅的神经毡处点 1–3 下 |
| 4 | 「③ 深染参考」 | 在深色斑块最密集处点 1–3 下 |
| 5 | 「计算」 | 约 1 秒；叠加图显示 ROI（蓝）、深染（红）、局灶（橙） |
| 6 | 「保存并下一张」 | 结果写入工程 |

全部完成后导出：

- `文件 → 导出逐张结果 CSV`
- `文件 → 导出 HTML 质控报告`
- `文件 → 保存工程`

## 3. 参数

| 参数 | 默认 | 何时修改 |
|---|---|---|
| 比例尺 | 0.4975 µm/px | 换物镜后必须按标尺重测 |
| 错误率 α | 0.01 | 需要敏感性分析时取 0.005–0.02 |
| 分解尺度 σ | 35 px | 胞体明显更大/更小时取 15–60 |
| 最小对象面积 | 12 µm² | 杂质多时可调大 |
| 颜色通道 | R | 复染明显时改 G 或 B |

## 4. 质控怎么读

- **参考对比偏低**：浅染与深染参考太接近，标定不可靠，应重新选点。
- **近似单峰**：ROI 内深染与浅染为连续过渡，面积比应理解为分布尾部占比。
- **置信区间过宽**：该张结果不稳，建议复核 ROI 与参考点。
- **候选面积剔除比例偏高**：检查切片折叠、染料沉淀，或调整最小对象面积。

## 5. 命令行

```bash
python main.py --cli --project batch.nqproj --out results.csv --report
```

日志写入输出目录的 `nisslquant_cli.log`。

## 6. 演示

```bash
python examples/make_demo.py
python examples/run_demo.py
```
