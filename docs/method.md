# 方法说明

## 记号

| 记号 | 含义 |
|---|---|
| I | 选定通道像素强度 |
| b | 黑电平 |
| L | 浅染参考区中位强度 |
| D | 深染参考区中位强度 |
| OD | 光密度，OD = −lg[(I−b)/(L−b)] |
| u | 标准化染色密度，u = OD / OD_D，u=0 对应浅参考，u=1 对应深参考 |
| f | 阈值位置（0=浅参考，1=深参考），默认 0.5 |
| τ | 强度阈值，τ = L − f·(L − D) |
| u_f | 局灶分量，u_f = u − G_σ*u |

## 阈值：为什么用中点

尼氏染色颗粒层的灰度分布通常单峰（本批 49 张中 95.9%），不存在可由谷底确定的自然分界。
在这种情况下，阈值是一个被指定的参数，而不是被发现的边界。软件采用两参考中点：

```
τ = L − 0.5·(L − D) = (L + D)/2
```

它的操作含义是：一个像素在光密度上更接近深染参考而非浅染参考时，判为深染。
这一规则不依赖直方图形态，也不会出现"阈值比深染参考本身还暗"的退化情况
（早期版本用浅参考 1% 尾定阈，在参考对比度低的 5 张图上阈值 u>1，导致几乎零检出，已废弃）。

**阈值位置是主要的不确定性来源。** 在 49 张图上把 f 从 0.4 移到 0.6（即阈值移动 ±0.1 跨度），
深染面积比的相对变化中位为 53.7%。软件因此同时计算 f=0.4、0.5、0.6 三个位置，
并在结果中并列输出（`daf_tau_low / daf_tau_mid / daf_tau_high`）。

## 步骤

### S1 区域限定

待测 ROI、浅染参考、深染参考位于同一张切片。浅参考取神经毡或低染色白质，深参考取深染细胞密集区，
各 1–3 处，采样半径 7 px。

### S2 光密度与标定

```
OD = −lg[(I − b) / (L − b)]
u  = OD / OD_D
```

u 用于多尺度分解、连续指标与质控；分割本身直接在强度域用 τ 完成。

### S3 多尺度分解

```
u_s = G_σ × u        （ROI 外用 ROI 中位数填充）
u_f = u − u_s
```

σ 默认 35 px，约等于一个颗粒细胞胞体直径。局灶分量用于 `focal_pct`，其阈值仍按浅参考零分布的单侧错误率确定。

### S4 分割与伪影剔除

- 整体掩膜：`I < τ`
- 局灶掩膜：`u_f > μ0f + z(1−α)·σ0f`
- 八连通域标记，计算面积、贴边比例、过饱和比例、长宽比、实心度
- 剔除：面积 < 12 µm²；贴边 > 60% 且面积 > 200 µm²；过饱和 > 50%；长宽比 > 8 且实心度 < 0.5

### S5 指标

```
DAF  = A_dark / A_ROI × 100%          （伪影剔除后，主指标）
DAF_raw = 阈值面积 / ROI 面积 × 100%   （剔除前）
FDF  = A_focal / A_ROI × 100%
DSI  = median(u_s[ROI])
ESL  = mean(max(0, u − τ_u))
```

### S6 不确定度与质控

- 对象级 bootstrap：对保留连通域面积有放回重采样 120 次，取 2.5%/97.5% 分位
- 参考对比度：C_ref = (OD_D−OD_L)/[σ_L/(L·ln10)]，< 3 判标定不可靠
- Sarle 双峰系数 < 0.555 → 提示单峰
- CI 宽度 > 5 pp、饱和 > 5%、伪影剔除 > 60%、DAF < 0.2% 或 > 50% → 告警
- 加权计分 → 优 / 良 / 可疑 / 不合格

## 与"自动阈值"的关系

软件不提供 Otsu、Li、Triangle 等自动阈值作为主流程。原因不是实现困难，而是这些方法在单峰分布上
给出的结果差异过大：本批 49 张图、11 种策略的深染面积比中位从 5.0% 到 93.5%，
同一张图跨方法极差中位 88.8 个百分点，组间推断的 P 值从 0.001 到 0.371，方向可以翻转。
在缺乏金标准的情况下，选择其中任何一种都只是选择了一种定义；软件选择的是"可由操作者用两个组织学参考
锚定、且能被读者复核"的那一种，并把它的敏感性如实输出。
