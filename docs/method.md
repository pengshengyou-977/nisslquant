# 方法说明

## 记号

| 记号 | 含义 |
|---|---|
| I | 选定通道像素强度 |
| b | 黑电平 |
| I₀ | 浅染参考区中位强度 |
| OD | 光密度，OD = −lg[(I−b)/(I₀−b)] |
| OD_L, OD_D | 浅 / 深参考的光密度 |
| u | 标准化染色密度，u = (OD−OD_L)/(OD_D−OD_L) |
| u_s, u_f | 低频分量与局灶分量 |
| μ₀, σ₀ | 浅参考零分布的中位数与稳健标准差 |
| α | 单侧错误率 |
| τ, τ_f | 整体与局灶检出限 |

## 步骤

### S1 区域限定

待测 ROI、浅染参考、深染参考位于同一张切片。浅参考取神经毡或低染色白质，深参考取深染细胞密集区，
各 1–3 处，采样半径 7 px。

### S2 两点光密度标定

```
OD = −lg[(I − b) / (I₀ − b)]
u  = (OD − OD_L) / (OD_D − OD_L)
```

u=0 对应浅参考，u=1 对应深参考。比值形式吸收曝光的整体缩放与相机增益的整体缩放。

### S3 多尺度分解

```
u_s = G_σ × u        （ROI 外用 ROI 中位数填充）
u_f = u − u_s
```

σ 默认 35 px，约等于一个颗粒细胞胞体直径。

### S4 零分布与检出限

```
μ₀, σ₀ = median(u[ref]), 1.4826·MAD(u[ref])
单侧精化：用 u < μ₀+1.5σ₀ 的 ROI 像素重估，σ₀ 不超过原值的 1.5 倍
τ = μ₀ + z(1−α)·σ₀
```

对 u_f 重复得到 τ_f。α 默认 0.01。

**不变性**：参考区移动导致 I₀、OD_D 变化时，u、μ₀、σ₀、τ 同步作仿射变换，
被判定为深染的像素集合保持不变。这是标定与零分布同源带来的代数结果。

### S5 分割与伪影剔除

- 整体掩膜：`u > τ`
- 局灶掩膜：`u_f > τ_f`
- 八连通域标记，计算面积、贴边比例、过饱和比例、长宽比、实心度
- 剔除：面积 < 12 µm²；贴边 > 60% 且面积 > 200 µm²；过饱和 > 50%；长宽比 > 8 且实心度 < 0.5

### S6 指标

```
DAF = A_dark / A_ROI × 100%
FDF = A_focal / A_ROI × 100%
DSI = median(u_s[ROI])
ESL = mean(max(0, u − τ))
```

### S7 不确定度与质控

- 对象级 bootstrap：对保留连通域面积有放回重采样 120 次，取 2.5%/97.5% 分位
- 参考对比度：C_ref = (OD_D−OD_L)/[σ_L/(I₀·ln10)]，< 3 判标定不可靠
- Sarle 双峰系数 < 0.555 → 提示单峰
- CI 宽度 > 5 pp、饱和 > 5%、伪影剔除 > 60%、DAF < 0.2% 或 > 50% → 告警
- 加权计分 → 优 / 良 / 可疑 / 不合格

## 与常规流程的差别

| 环节 | 常规流程 | NisslQuant |
|---|---|---|
| 阈值 | 浅/深参考中位强度的中点 | μ₀ + z(1−α)·σ₀ |
| 参考点影响 | 直接决定阈值 | 严格不变（仿射） |
| 尺度 | 单尺度 | 弥漫 + 局灶双尺度 |
| 去噪 | 3×3 开运算 | 连通域形态学规则 |
| 不确定度 | 无 | 对象级 bootstrap 95%CI |
| 质控 | 硬编码报警 | 五项指标 + 四级分级 |
